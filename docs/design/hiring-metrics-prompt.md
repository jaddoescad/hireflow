# Hiring metrics reference

Design reference for HireFlow hiring CRM metrics page, desktop UI screenshot, clean restrained SaaS interface, ivory background, dark forest green accents, slim left sidebar HireFlow logo and Hiring, Metrics selected, Team, Settings. Main heading Hiring metrics, compact date range From/To with Date basis Application date dropdown and experience/role/source/stage filters. Four simple summary cards Applications 128, Unique contacts 121, Active stages 7, Missing dates 0. Chart Applications over time daily bars in forest green; adjacent Experience breakdown horizontal bars 5+ years, 3–5 years, 1–2 years, Less than 1 year, Unknown. Below Current hiring stages horizontal counts Applied 70, VA call 25, Manager interview 14, Painting trial 7, Hired 4, Rejected 5, Saved for later 3. Clearly label synthetic sample data, no real people or company info. Crisp accessible typography, meaningful compact layout, no gradients decorative illustrations or unnecessary panels, not Hermes CRM. Show sensible responsive component structure.

Implementation adapts the compact filters, summary cards, trend and horizontal breakdowns to HireFlow's existing navy/blue palette. All example figures in the reference are synthetic. Current stage distribution is not a historical conversion funnel.
